# Todo Eisenhower Matrix

A modern, Jetpack Compose-based Android application designed to help you prioritize tasks using the **Eisenhower Matrix** method.

## Features

- **Matrix Categorization**: Easily categorize tasks based on their urgency and importance:
    - **Do First**: Urgent and Important
    - **Schedule**: Important, but not Urgent
    - **Delegate**: Urgent, but not Important
    - **Eliminate**: Neither Urgent nor Important
- **Task Management**: Create, edit, and delete tasks with ease.
- **Smart Timing**:
    - Set **Due Dates** using a standard date picker.
    - Set **Reminders** with a combined date and time picker that respects your system's 24-hour format settings.
- **Visual Feedback**: Mark tasks as complete directly from the list with clear visual indicators (strike-through text).
- **Modern UI**: Built entirely with **Jetpack Compose** and **Material 3** for a smooth, adaptive user experience.

## Tech Stack

- **UI**: Jetpack Compose, Material 3
- **Architecture**: MVVM with ViewModel and StateFlow
- **Language**: Kotlin
- **Time Handling**: java.time (LocalDate, LocalDateTime)

## Getting Started

1. Clone the repository.
2. Open the project in **Android Studio**.
3. Build and run the app on an emulator or physical device.
